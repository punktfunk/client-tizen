## The gates, in order

1. **T1, the tunnel from a desktop browser.** Host `.21` rebuilt from monorepo `main`. In a
   client-web checkout at `main`: `npx vite` in `apps/web` with `PF_HOST` unset, then open
   `http://127.0.0.1:5173/_e2e.html?tunnel=1&host=192.168.1.21` in Safari. It pairs (Request
   access, or `&pin=`) and lists the library through the tunnel; the page-server and direct paths
   are unchanged. D5 (a host with Browser origins set admits a client with no `Origin`) is tested
   with the TV, not with Safari, whose page does send one.
2. **T2, the package on the monitor** (ask before each install): `npm run build` here on the Mac
   Studio, `tools/sign.sh`, `TV=192.168.5.63 tools/sign.sh install`. Add `.21` by address,
   Request access, approve in the host console, library and covers. A USB keyboard is allowed.
3. **T3, by remote only**: first launch → add host → Request access → library →
   launch → stream → Back → menu → Disconnect → Back at the root → exit prompt → exit; relaunch,
   still paired.
4. **T4** per the plan's §8 against `.21` and `.173`; then correct the scope lines on the install
   page and the codec gate in client-web's `video.ts` if HEVC turns out to be software.
5. **T5**: tag `v0.1.0` here once the gates pass; install the release asset once through
   Apps2Samsung; with the maintainer's yes, open the catalog PR with
   `catalog/punktfunk__client-tizen.json`.

## Choices made while implementing

- A 30 s per-request read timeout on the tunnel beside the plan's caps, so a silent stream cannot
  hold a slot and defeat the idle close.
- `PeerCertFingerprint(None)` is stamped on tunnelled requests as the plain listener stamps it.
- Paths are checked raw and percent-decoded; dot and empty segments are refused; `is_confined` is
  unchanged by D5.
- The management port's plain router is `None` while the plane is off: no sniff at all.
- `HostTarget.tunnel` names the route; the bootstrap doubles as the reach probe; a plane-off host
  reads "Browser streaming is off on this host…".
- The TV keyboard field uses `inputmode` `numeric` for a PIN or a port and `decimal` for an
  address. A typed hostname is not enterable with either, which is decision D4.
- The quick menu's first row on a TV is *Disconnect, keep the game running*, not End stream.
- Package id `punktfunk0`, application id `punktfunk0.punktfunk`, widget id
  `https://github.com/punktfunk/client-tizen`. Fixed for the life of the app.
- The console kit's codec row on Tizen is `[auto, hevc, h264]`, like webOS.
- The install page states H.264/HEVC up to 1080p60 and no AV1/HDR/4K as the scope until T4
  corrects it.
